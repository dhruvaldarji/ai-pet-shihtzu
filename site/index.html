Start here

Install Louis locally

  1. Choose a versioned package. Before extracting, obtain its release.json and SHA256SUMS from a separately trusted published source. The outer checksum file covers all eight data files plus release.json; sha256sum -c SHA256SUMS (or shasum -a 256 -c SHA256SUMS) checks the complete set. For a ZIP-only download, compare its hash with the Louis ZIP descriptor in the trusted manifest.
  2. After extraction, verify the package's inner SHA256SUMS with sha256sum -c SHA256SUMS or shasum -a 256 -c SHA256SUMS from the extracted folder.
  3. Run sh install.sh in that verified folder. The local root is the first non-empty value of LOUIS_CODEX_DIR, CODEX_HOME, or $HOME/.codex.
  4. Use that same root for later updates and uninstall. Select Louis in the app if needed and check its appearance.

Checksums detect changed bytes, not publisher identity. A successful script only establishes local file installation, not visible playback or cloud delivery. Preview artifacts are not published downloads.

Keep your copy

Update an existing Louis

Verify and extract the newer version, then run its sh install.sh using the same local root and pet ID. An identical payload is a no-op. A changed payload preserves custom files and keeps the complete previous Louis in pet-backups/ before replacement. Other pets stay unchanged.

Updates are user-requested. There is no background updater, automatic release download, or cloud-upload fallback.

Keep control

Uninstall or restore

Run sh uninstall.sh from the verified package with the same root. Louis is moved to a complete backup; repeated removal while absent is a no-op.

To restore, close the app and stop other pet operations. Preserve any current Louis by uninstalling it first, then copy the complete backup louis folder to the now-absent, non-symlink <root>/pets/louis path. Never merge or overwrite. Keep the backup until you reopen the app and check the restored pet.
